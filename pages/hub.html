PROTOCOLO DE APRENDIZAJE ABIERTO & DESCENTRALIZADO

Tu Progreso, Rutas y Desafíos Guardados en Repositorios Git

Prig Hub rechaza las plataformas cerradas con suscripciones de pago. Tu plan de estudio, tus notas y tus desafíos de código viven en texto plano (YAML & Markdown) dentro de un repositorio Git bajo tu control absoluto, sincronizable con GitHub, GitLab, Codeberg o servidores locales.

Explorar el Formato Volver al IDE
REPO: usuario/prig-machine-learning
Estructura del Pack / Perfil prig.yaml (v1)
├── 📄 prig.yaml (Manifiesto, autor, nivel y licencia)
├── 📄 personas.yaml (Canales y autores a seguir)
├── 📄 recursos.yaml (Datasets, papers, videos y cursos)
├── 📁 rutas/ (Roadmaps en Markdown con pasos)
│   └── 📄 deep_learning_senior.md
└── 📁 desafios/ (Ejercicios de código con tests)
Sincronización Canónica Universal:
Los recursos usan claves estables (youtube:video:id, kaggle:dataset:id, github:repo:id). Tu progreso se mantiene sincronizado entre todos tus packs.
FILOSOFÍA DE DATOS

¿Por qué Prig Hub usa Repositorios Git?

Tus conocimientos no deben depender de la base de datos propietaria de ninguna empresa.

100% Texto Plano (YAML/Markdown)

Cualquier persona puede leer, editar a mano o auditar un pack de estudio con cualquier editor de texto, con Prig IDE o sin él.

HUMAN READABLE

Versionado Semántico Real

Historial de cambios con git log, bifurcaciones (forks), pull requests colaborativos y control de versiones semántico (ej. 1.2.0).

GIT POWERED

Identidad Canónica Inmutable

Los recursos se identifican por su enlace normalizado. Si un video aparece en dos rutas distintas, Prig sincroniza el progreso automáticamente en ambas.

CANONICAL IDS

Rutas de Estudio Estructuradas

Archivos rutas/<id>.md donde cada ítem de lista es un paso pedagógico con metas, enlaces directos a videos o repositorios y notas.
